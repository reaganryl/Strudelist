STEP64 CHORDS / ARPS

4 parts · 64 steps each · offline

Tap steps, choose chords and arpeggios. Press Play for local sound.

Live MIDI requires browser Web MIDI support and a MIDI output already exposed to Android. Bluetooth MIDI pairing alone may not expose a device to this page. MIDI-file export works without hardware.

Neo-soul / jazz chord & arp arranger · 4 voices

Each part has one chord, sound, arp mode, across all 64 steps; global transpose affects all four parts. Instrument changes send General MIDI program changes; local preview uses approximate oscillator sounds. Saved locally.

MIDI export plays all 4 measures, with tempo and four MIDI channels. Open the .mid file on the Patchbox Pi 5 or another MIDI sequencer and route it to FluidSynth.

How it works + routing

In a Web MIDI-capable browser, Enable MIDI enumerates available outputs. Selecting one sends four parts on MIDI channels 1–4, with general MIDI program changes. For FluidSynth on the Pi, a USB MIDI interface or network MIDI bridge may be needed: browsers cannot send directly to an arbitrary FluidSynth process. A downloaded MIDI file is the most dependable first route.

Android browser audio may pause when the screen locks. Synth preview is deliberately simple; FluidSynth will provide richer sounds using your installed SoundFonts. Keep amplifier volume low when testing.
